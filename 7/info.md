* `AhoCorasick(patterns, verbose)` — конструктор автомата.

  Внутри:

  * `this.patterns` — массив шаблонов (строк), которые нужно искать.
  * `this.patLen` — длины шаблонов (используется при вычислении стартовой позиции вхождения).
  * `this.nodes` — массив узлов автомата. Каждый узел — объект `{ next: {}, link: 0, out: [] }`:
    * `next` — словарь переходов по символу (как в trie);
    * `link` — суффиксная ссылка (failure link) — используется при несовпадении;
    * `out` — список индексов шаблонов, которые оканчиваются в этом узле (может быть несколько — перекрывающиеся шаблоны).
* `_newNode()` — создаёт новый узел и возвращает его индекс.
* `buildTrie()` — строит префиксное дерево (trie): для каждого шаблона идём по символам, создаём переходы `next` по необходимости, и в конце узла добавляем `pid` в `out`. В результате в trie у нас есть все шаблоны как пути от корня.
* `buildLinks()` — строит суффиксные (failure) ссылки методом BFS:

  * Инициализируем очередь детьми корня: их `link = 0`.
  * Для каждого узла `v` обходим его переходы `next[ch] = u`. Чтобы посчитать `u.link`:
    * берём `f = v.link` и поднимаемся по `link`, пока не найдём `nodes[f].next[ch]` или дойдём до корня;
    * если в `f` есть переход по `ch`, то `u.link = nodes[f].next[ch]`, иначе `u.link = 0`.
  * После установки `u.link` мы наследуем все выходы (out) от `u.link` — т.е. `nodes[u].out` дополняется `nodes[u.link].out`. Это даёт возможность обнаруживать шаблоны, которые являются суффиксами других.
* `build()` — просто `buildTrie()` + `buildLinks()`.
* `search(text, verboseSteps)` — основная функция поиска в тексте:

  * Инициализируем `cur = 0` (корень).
  * Проходим по каждому символу `ch` текста (позиция `pos`):
    * Пока `cur != 0` и нет перехода по `ch` — делаем `cur = nodes[cur].link` (падаем по failure links).
    * Если `nodes[cur].next[ch]` существует — переходим `cur = nodes[cur].next[ch]`, иначе остаёмся в корне `cur = 0`.
    * Если в текущем узле `nodes[cur].out` не пуст — для каждого `pid` в `out` считаем стартовую позицию вхождения: `start = pos - patLen[pid] + 2` (здесь 1-based позиции) и добавляем её в результаты `results[pid]`.
  * Возвращаем массив `results`, где `results[i]` — список позиций вхождений `patterns[i]` в тексте.
* `printAutomaton()` — удобный дамп узлов: переходы, link, out (печатает в консоль).
* `main()` — парсит аргументы командной строки (`-v` для verbose), читает файл, создаёт automaton, запускает `build()` и `search()`, печатает результаты.
